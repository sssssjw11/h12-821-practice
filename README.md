# H12-821 数通刷题

用于集中复习 H12-821 的中文刷题网页，包含 **485 道题、21 章知识精讲**。支持电脑和手机浏览器。

## 功能

- 按章节、题型、题量练习，随机抽题与原题号搜索。
- 单选、多选、判断和填空判分；查看原答案、解析及对应章节精讲。
- 错题订正、收藏、答题卡、刷新续做和练习统计。
- 学习进度保存在当前浏览器，可导出、导入 JSON 备份。
- 注册、登录同步账号，在同一服务器上的不同设备之间同步作答、错题、收藏和练习位置；同时修改时提示选择保留版本。
- 21 章精讲按知识点组织，附速记要点与 3–7 天学习安排。

题库覆盖原题号 003–487，移除了两条广告记录，仅包含 821。461 道题可自动判分，另 24 道题需要人工核对，其中 Q52、Q188、Q237、Q399 的原答案存在争议。原题答案和解析保留来源口径，核对提示可在网页中查看。

## 直接运行

仓库已包含构建完成的 `dist/`，只需 **Node.js 18 或更高版本**，无需安装依赖：

```bash
git clone https://github.com/sssssjw11/h12-821-practice.git
cd h12-821-practice
node server.mjs
```

打开 `http://127.0.0.1:8210/`。Windows 也可双击 [启动刷题.cmd](启动刷题.cmd)。新版 Node 服务同时提供网页和同步 API，运行数据写入 `data/`，无需安装数据库。

## 上传服务器

下载 [h12-821-practice-server.zip](h12-821-practice-server.zip) 并解压，在解压后的目录执行：

```bash
node server.mjs --host 0.0.0.0 --port 8210
```

打开 `http://服务器IP:8210/`，并在服务器防火墙或云安全组放行对应端口。也可直接克隆仓库，运行同一命令。详细说明见 [服务器部署说明](服务器部署说明.md)。

使用 Nginx 时，将整个站点代理到 Node 服务，包含 `/api/`。只托管 `dist/` 可以本地刷题，但无法登录或跨设备同步。完整反向代理示例、数据备份及升级步骤见 [服务器部署说明](服务器部署说明.md)。

两台设备必须访问同一个服务器并登录同一个账号。不同服务器之间的数据库独立，账号不会自动互通。账号同步失败时仍可在已打开的页面离线刷题，联网后重试；同步状态在页顶显示。未登录的旧浏览器进度可以登录后通过“迁移到当前账号”导入，原缓存保留。

## 修改源码

开发构建建议使用 Node.js 22 或更高版本及 pnpm：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

开发页面地址为 `http://127.0.0.1:8211/`。需要测试登录与同步时，在另一个终端运行 `node server.mjs`，Vite 会将 `/api/` 代理到本机 8210；纯前端开发可忽略后端不可用提示。也支持 `npm install` 后使用对应的 `npm run` 命令。

```bash
pnpm typecheck
pnpm test
pnpm test:server
pnpm build
```

修改题库请编辑 `public/bank.json`，再重新构建以更新 `dist/`。`scripts/build_bank.py` 是原始学习资料的转换工具，需另外提供已整理的学习资料目录，并用 `--source` 指定；日常运行和构建不需要这些原始资料。

## 项目文件

| 文件                          | 用途                                               |
| ----------------------------- | -------------------------------------------------- |
| `src/`                        | React、TypeScript 网页源码                         |
| `public/bank.json`            | 485 道题及 21 章精讲                               |
| `tests/`                      | 判分、题库完整性、进度保存和导入验证               |
| `dist/`                       | 可直接运行的生产页面                               |
| `server.mjs`                  | 零依赖 Node.js 静态服务器                          |
| `server/`                     | 账号、同步接口、持久化存储和生成的共享判分校验代码 |
| `data/`                       | 运行时账号与进度，自动创建，不进入 Git 和发布包    |
| `h12-821-practice-server.zip` | 上传服务器的完整部署包                             |
| [使用说明](使用说明.md)       | 本地启动与进度备份                                 |

源码采用 React 19、Vite 6、TypeScript。后端使用 Node.js 内置模块，密码以加盐 scrypt 派生值保存，会话通过 HttpOnly Cookie 管理。当前存储适合个人或小组使用：单个 Node 进程独占一个数据目录，文件写入串行执行并原子替换；不支持多个进程共享同一个目录。

未登录时，作答记录保存在浏览器 localStorage；登录后同时保留本设备缓存并同步到服务器。清理浏览器数据前，确认显示“已同步到服务器”或导出备份。题目图片引用原始远程地址，需要访问图片源站；加载失败时可重试或打开原图。
